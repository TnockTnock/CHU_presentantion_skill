# Проверка оригинального шаблона — 28 сентября 2026

> Обновление: пользователь отклонил стилистическое качество контрольной сборки. Приведённые ниже прежние результаты подтверждают технические проверки, но не визуальную приёмку. Смотрите [исправления по Figma](card-system.md).

## Покрытие

Инвентаризированы 82 слайда, 77 layout и 12 master; все 77 layout представлены среди кандидатов 6–82. Слайды 1–3 — инструкции, 4–5 — иконки. Выделены 18 семейств и 76 сигнатур геометрии. Сигнатура не доказывает уникальность дизайна: графика, цвет и назначение проверяются отдельно. Реестр хранит варианты без их удаления.

Для 77 кандидатов реализованы адаптеры конкретных полей. Статус — **implemented**, не безусловная полная поддержка. Автоматический структурный тест собирает все 77, проверяет значения и наследование. Отдельный тест повторного использования проверяет независимость текста, унаследованного от layout исходного слайда 74.

## Выполненные проверки

- Полный unittest-набор: **50 тестов, 50 пройдено, 0 ошибок, 0 пропусков**. Включены три существовавших интеграционных PPTX и две проверки изображений оригинального режима. Точный лог: `assets/catalog/original/qa/tests-full.txt`.
- Пиксельное сравнение пустых копий: **77/77**, нулевое отличие, одинаковый LibreOffice/Poppler, Golos Text и 1440 px. Результат каждого слайда: `assets/catalog/original/qa/visual-regression.json`.
- Независимо собранные и отрендеренные 18 слайдов, по одному из каждого семейства: **18/18** совпали с заполненными эталонными PNG каталога.
- Просмотрены все 7 контактных листов заполненной сборки (77 слайдов), 2 листа разнообразной сборки (18 слайдов), инструкция и иконки источника. Это обзор контактных листов, не ручная проверка каждого глифа при увеличении.
- Исправлены кадрирование фотографий с наследуемым fillRect, пересечение графиков с подписями, повторный осиротевший placeholder, время в узкой области, текст layout исходного слайда 74 и поле, частично выходящее за холст.
- Негативные тесты обнаруживают изменение исходного layout, значений графика и таблицы, переполнение, защищённое поле, неверную классификацию и пиксельную регрессию.
- Проверена упаковка и установка профилей, включая Hermes. Самостоятельные запуски внутри Claude/Hermes отдельно не проводились.

## Границы результата

PowerPoint для Windows/macOS не запускался. Шрифты не встроены. Автоматический тест каждого сочетания максимальной длины, числа серий, фото и маски не выполнен. Текстовые ограничения предварительные и требуют повторного рендера с рабочими данными. Не все необязательные изображения заменяются в контрольной сборке; серые области мокапов намеренно остаются пустыми.

Добавленные текст, таблицы и графики редактируемы. Исходный растровый декор и некоторые схемы не становятся редактируемыми связями. Нативные графики поддерживают bar/line и добавляются в оригинальную область; оригинал не содержит готовых нативных графиков для точного копирования их оформления.

Заметки оригинального режима пока выводятся в scenario.md, источники — в sources.json. Автоматическая проверка адресуемости source_ids и запись в заметки PowerPoint отсутствуют. Проверки evidence_policy формата `/2` не применяются автоматически к `/1` оригинального режима.

Вспомогательный quick_validate.py для SKILL.md не удалось запустить из-за отсутствующего полного PyYAML в окружении. Это не ошибка 50 тестов сборщика; не заявляется прохождение отдельного валидатора скиллов. CI на других ОС в этом локальном отчёте не считается выполненным.

## Следующие условия для расширения статуса

1. Проверить PPTX в PowerPoint, включая редактирование графика через вложенную XLSX и повторное сохранение.
2. Проверить все необязательные изображения и границы содержимого по отдельным адаптерам; добавить устойчивые заполненные эталоны для каждого случая.
3. Дополнить оригинальный контракт проверкой источников и нативными заметками.
4. Отдельно реализовать редактируемую топологию там, где исходная схема растровая.

Нейтральная сборка предназначена для проверки системы и не является фактическим отчётом или презентацией Ai Everything.
