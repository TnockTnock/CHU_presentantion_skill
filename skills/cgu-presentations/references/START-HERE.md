# Презентации ЦГУ: начало работы

Это пакет для тестирования коллегами. Он создаёт редактируемый PPTX из оригинальных корпоративных слайдов. Агент готовит содержание; один Python-сборщик обслуживает Claude, Codex, Hermes и другие среды с файлами и терминалом. Клиенты и модели по отдельности ещё не прошли приёмку.

## 1. Установка

Распакуйте ZIP целиком. Откройте терминал в `cgu-presentations` — рядом с `SKILL.md`. Нужен Python 3.9+. В Windows вместо `python3` используйте `py -3`.

Установите в проект, который будете открывать в агенте (замените путь):

```sh
python3 scripts/skill_package.py install --agent codex --project "/path/to/project"
# Claude Code: замените codex на claude.
# Hermes: установите в папку навыков вашего экземпляра:
python3 scripts/skill_package.py install --dest "/path/to/hermes/skills/cgu-presentations"
```

Установщик не меняет настройки агента и не устанавливает сам агент. Для обновления добавьте `--replace`: прежняя версия сохраняется в резервной копии. Откройте новую сессию агента. Если автоматическое обнаружение отсутствует, дайте полный путь к SKILL.md и попросите прочитать его. Для веб-чата без Python доступен только план, не сборка PPTX.

Установите шрифты из `assets/fonts/` средствами ОС. Для PPTX достаточно Python; для PDF и PNG нужны LibreOffice и Poppler (либо PyMuPDF). Диагностика:

```sh
python3 scripts/run.py doctor --backend portable
```

## 2. Проверка именно нашего шаблона

Из распакованной папки выполните:

```sh
python3 scripts/run.py original-init --out starter
python3 scripts/run.py build starter/deck.json --backend portable --no-render --out first-result
```

Откройте `first-result/output/presentation.pptx`. Это четыре нейтральных контрольных слайда из исходных композиций 12, 14, 16, 18, а не готовая презентация. Проверьте шрифты, скругления и редактирование текста. Для PDF уберите `--no-render` и используйте новую выходную папку.

Другие варианты выбираются в `assets/catalog/original/index.html`. Чтобы получить поля конкретных исходных слайдов:

```sh
python3 scripts/run.py original-init --layouts original-06 original-14 original-18 --allow-experimental --out selected
```

`--allow-experimental` включает непроверенные визуально варианты только для осознанного теста. Сборка сохраняет исходные объекты и наследование layout/master/theme. Декоративные растровые схемы не становятся редактируемыми связями.

## 3. Запрос агенту

> Прочитай SKILL.md установленного cgu-presentations. Сделай презентацию по приложенному материалу для [аудитория], цель — [решение], объём — [число слайдов]. Используй оригинальные корпоративные композиции из каталога. Сначала сопоставь смысл каждого слайда с подходящим шаблоном, затем заполни его поля. Сохрани Golos Text, заголовки SemiBold, цифры Bold, скруглённые блоки и умеренные цветовые акценты. Не заменяй разные композиции одной текстовой сеткой. Не придумывай факты. Проверь каждый итоговый слайд. Выдай PPTX, PDF при доступном экспорте и короткий список непроверенного.

Агент сохраняет ключи `fields` и `layout_id`, меняет содержимое и добавляет источники. `demo: true` разрешён только для синтетической проверки. Для рабочего отчёта нужны источники; [content-model.md](content-model.md) описывает общий контракт. Если текст не помещается — сократить с сохранением смысла или разделить слайд, не уменьшать шрифт автоматически.

## 4. Что передать по итогам теста

Название/версия агента и модели, ОС, команда, текст ошибки либо номер слайда и скриншот проблемы. Проверьте: установка → собственные данные → PPTX → открытие → изменение текста → сохранение → повторное открытие. Не отправляйте закрытые данные в публичные issues. Встроенный структурированный feedback хранит только layout_id, intent, density и категорию проблемы.
