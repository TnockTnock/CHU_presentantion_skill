# Выпуск для тестирования коллегами — 29 сентября 2026

Статус: pilot / release candidate, не production. Основной пользовательский маршрут: original-init → собственное содержание → validate → build original-portable → просмотр PPTX/PDF. Тестовый пример не выдаётся за презентацию пользователя.

## Проверено

- Полная инвентаризация: 82 страницы / 77 layout / 12 master, 77 контрактов адаптеров, 18 семейств. Страницы 1–3 — инструкции, 4–5 — иконки. Оригинальные layout/master/theme защищены проверкой целостности.
- 75 автоматических тестов: основной набор 73 и 2 проверки стартового проекта/готовности. Итоговый лог прилагается к тестовому пакету.
- Нагрузочная матрица: 1155 комбинаций, 525 приняты и отрендерены, 277 отклонены, 353 неприменимы. Все 77 проходят minimum, normal и missing-optional. Это не одобрение 525 изображений человеком.
- Общая модель источников/утверждений в original и semantic; Notes внутри PPTX; контроль шести компонентов KPI; журнал решений по исходному содержанию.
- Стартовый проект из оригинальных 12, 14, 16, 18 собран в PPTX/PDF; все четыре PNG просмотрены, видимых наложений и обрезанного текста не найдено. Повтор фото в нейтральном сравнении — тестовый заполнитель.
- Пять ранее собранных регрессионных колод прошли проверки Notes, структуры и сохранности содержания. Четыре — синтетические, пятая — локальный материал, не включённый в публичный пакет.

## Что не подтверждено

- Production 0; usable 4; experimental 73. Binding tested и content stress-tested не равны visual approved. Политика production отклоняет все текущие композиции.
- PowerPoint установлен, но открытие тестового файла через UI не удалось: ввод пути не сохранялся, clipboard timeout. Редактирование, сохранение, повторное открытие и экспорт PowerPoint не проверены. Экспорт LibreOffice не заменяет эту проверку.
- Не запускались реальные сессии каждой модели в Claude, Codex и Hermes. Проверка установки и CLI из их папок проверяет переносимость файлов, а не качество рассуждений модели.
- Текущие изменения проверены на macOS. Прежний Windows/Linux CI не является доказательством текущего выпуска.
- Подбор — прозрачные эвристики по intent, структуре и вместимости; не полноценное понимание takeaway. Геометрические fingerprints приблизительные. Semantic-композиции не имеют полной production-приёмки.
- Декоративные растровые схемы оригинала не редактируются как граф. Для новых связей существует отдельный native-режим.
- Полная визуальная приёмка 77 вариантов, стресс-проверки логотипов/лиц/всех разрешений и независимый тест коллег остаются открытыми. Внешняя достоверность фактов не проверялась.
- Системный quick_validate.py не запустился из-за отсутствия PyYAML; встроенные тесты ресурсов и сборки выполнены. Этот запуск не отмечен как успешный.

## Изменения для пользователя

START-HERE.md — короткая установка и первый корпоративный запуск. original-init создаёт редактируемую спецификацию с переносимыми изображениями. Общий demo больше не является стартовой рекомендацией. Документация Notes синхронизирована с кодом. readiness_policy теперь исполняется, а не просто принимается схемой. feedback-file подключает обезличенную обратную связь к original-select.
