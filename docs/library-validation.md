# Проверка обновления библиотеки — 24.09.2026

В локальный каталог включены 116 входных PDF/PPTX, 107 уникальных файлов, 361 отрендеренная страница и 307 различных изображений страниц при масштабе 960 px. Исходные файлы не изменялись. 10 выбранных композиций просмотрены отдельно; остальные прошли обзор на контактных листах. Наличие рендера не означает проверку достоверности исходных данных или оригинальных шрифтов.

Публичный пакет содержит только обезличенные описания семейств, код и синтетические контрольные превью. Пути, имена файлов, извлечённый текст и исходные превью находятся в локальном игнорируемом каталоге. Карты, портреты, внутренние показатели и скриншоты не переносились в распространяемые ассеты.

Сборщик расширен с 8 до 11 типов: KPI-группа, сравнение двух вариантов и дорожная карта. Добавлены редактируемые подписи связей, объектные источники и preflight реестра. Все 7 старых PNG побайтно совпали с предыдущей проверенной сборкой. 5 новых слайдов просмотрены по отдельности, Golos подтверждён инвентаризацией PDF. Структурная проверка подтверждает текстовые объекты и привязанные стрелки, но ручное редактирование в Microsoft PowerPoint не проверялось.

20 тестов прошли, включая оба интеграционных набора:

```bash
CGU_TEST_DECK=<base-demo.pptx> CGU_LIBRARY_DECK=<library-demo.pptx> python3 -m unittest discover -s tests -v
```

Проверены: повтор композиции, сопоставимые строки сравнения, неизвестные узлы, наложение подписи на узел, обязательные объектные источники, конфликтующие данные, неверный shape id и SHA, локальный поиск, изменение нативного KPI и подписи стрелки. Валидатор скилла пройден.

Ограничения: PNG подтверждают композицию тестовых примеров, а не любой объём текста. Гант, архитектурные слои, карты и совмещённый статусный реестр остаются референсами. Новый roadmap показывает порядок и периоды, но не масштаб длительностей. Автоматического извлечения смысла из документов, проверки истинности источников и универсальной адаптации всех 82 макетов нет.
