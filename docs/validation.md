## Подтверждённые результаты

- Демонстрация: 7 страниц, исходные пропорции 1440×810 pt, логотипы исходного шаблона.
- Визуально просмотрены все 7 страниц PDF-рендера. Финальные PNG совпадают побайтно с просмотренной исправленной сборкой.
- В PDF выявлены только GolosText-Regular и GolosText-SemiBold (с префиксами subset). В PPTX после нормализации нет посторонних явных font declarations.
- PPTX прошёл штатные integrity/layout/font/native-chart проверки и повторный импорт Artifact Tool.
- Процесс и архитектурная схема содержат 6 нативных connectors суммарно. Проверены привязки from/to и стрелки на целевом конце.
- График содержит 2 ряда исходных значений и встроенный workbook snapshot. Таблица содержит исходные строки и колонки.
- 11 автоматических тестов прошли, включая интеграционную проверку готового файла и обнаружение намеренно развёрнутой стрелки.
- Штатный валидатор скилла: `Skill is valid!`.

В ходе визуальной проверки исправлены исчезновение логотипов на обложке, обратные стрелки и стили границ таблицы. Отдельный пример `edge-cases.json` проверяет обычный текст, кириллицу, ₽, нули и отрицательные величины в столбчатом и линейном графиках. Подписи категорий перенесены к нижней границе, чтобы не лежать поверх отрицательного столбца.

## Повторить

```bash
python3 -m unittest discover -s tests -v
python3 skills/cgu-presentations/scripts/run.py demo --out work/demo-new
CGU_TEST_DECK="$PWD/work/demo-new/output/presentation.pptx" python3 -m unittest discover -s tests -v
python3 skills/cgu-presentations/scripts/run.py build skills/cgu-presentations/examples/edge-cases.json --out work/edge-new
```

Без `CGU_TEST_DECK` интеграционный тест пропускается, 10 остальных выполняются. Для визуальной проверки откройте PNG каждого слайда. Отчёт finalizer и хеш готового файла находятся в `qa/` конкретного запуска. Пользовательские материалы и большие результаты тестов в Git не включаются.

## Ограничения

Не проверено ручное редактирование в Microsoft PowerPoint/Google Slides. Шрифты в PPTX не встроены. Автоматический адаптер охватывает восемь типов на четырёх страницах короткого шаблона, а не все 82 страницы полной библиотеки. Визуальную проверку новой презентации нельзя заменить прохождением этих тестов.
