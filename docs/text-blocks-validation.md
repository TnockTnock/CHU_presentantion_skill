# Текстовые шаблоны и начертания · 2026-09-24

В библиотеку добавлены шесть адаптированных композиций: открытые колонки, сетка 3 + 2, колонки с выводом, контекст и акцент, показатели с выводом, текстовые колонки. Исходное содержание пользовательских презентаций не включено. Публичный набор содержит нейтральный PPTX/PDF, JSON и PNG; локаторы оригиналов и обзорные листы остаются в игнорируемой рабочей папке.

Заголовки — Golos Text SemiBold 600. Числа — Bold 700, включая числовые фрагменты заголовков и основного текста, таблицы, нумерацию и нативные подписи графиков. Regular 400 остаётся основным текстом. Смешанные числовые категории графика целиком Bold: ограничение форматирования нативной оси описано в правилах.

Проверки:

- 25 Python-тестов, включая три интеграционных теста на сгенерированных PPTX, прошли без пропусков.
- Негативные проверки обнаруживают потерю текста, неверное начертание, перепутанные стрелки и ошибки ссылок на источники.
- Сборка и финальная проверка трёх наборов: 6 новых блоков, 7 базовых слайдов, 5 дополнительных композиций.
- Все 18 PNG просмотрены отдельно; переполнений текста не обнаружено. PDF содержит Regular, SemiBold и Bold без замены семейства.
- Валидатор skill-creator пройден. Оригинальные файлы шаблона сохранили контрольные суммы.

PPTX сохраняет нативные текстовые объекты. Шрифты не встроены; файлы трёх начертаний поставляются в assets/fonts. Редактирование вручную в Microsoft PowerPoint не проверялось.
