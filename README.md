# Презентации ЦГУ

Единый скилл подготовки презентаций ЦГУ / ДИТ: фирменный PPTX-шаблон, Golos Text, редактируемые схемы и инфографика, проверка источников и результата.

## Состав

- `skills/cgu-presentations/SKILL.md` — точка входа скилла.
- `skills/cgu-presentations/references/` — правила типографики, схем, структуры проекта и QA.
- `skills/cgu-presentations/assets/templates/` — полный и короткий шаблоны с SHA-256.
- `skills/cgu-presentations/assets/fonts/` — Golos Text с лицензией OFL.
- `skills/cgu-presentations/scripts/audit_template.py` — инвентаризация OOXML без внешних зависимостей.
- `tests/` — проверки ресурсов и аудита.

## Локальная работа

Требуется Python 3.9+. Команды выполняются из корня репозитория:

```bash
python3 -m unittest discover -s tests -v
python3 skills/cgu-presentations/scripts/audit_template.py \
  skills/cgu-presentations/assets/templates/cgu-full.pptx \
  --out work/full-audit.json
```

Для тестирования поведения агента укажите ему путь к `skills/cgu-presentations/SKILL.md` и задачу. Например: «Используй скилл из этого файла, подготовь структуру презентации ЦГУ и схему процесса по приложенному материалу». Не требуется глобальная установка для чтения скилла по пути.

Сохраняйте тестовые презентации, отчёты и превью в `work/`: этот каталог исключён из Git. Исходные данные реальных презентаций не являются ресурсами скилла и не должны попадать в коммиты автоматически.

## Синхронизация

GitHub и локальная копия синхронизируются командами Git, не автоматически. Перед работой: `git pull --ff-only`. Для изменений создавайте ветки `codex/<задача>`, запускайте тесты, проверяйте diff и отправляйте коммиты в GitHub. Не редактируйте параллельно архивную копию скилла из исходной рабочей папки: актуальная версия находится в этом репозитории.

## Текущая готовность

Готов процедурный скилл с ресурсами и аудитом. Универсальный сборщик под новые шаблоны и автоматический каталог заполняемых полей пока не реализованы. Аудит не разрешает полное наследование стилей и не заменяет визуальную проверку PPTX/PDF. Полный цикл создания презентации новым процессом ещё предстоит проверить.

Старый сборщик рассчитан на другие 87 прототипов и размер 720×405 pt. Здесь хранятся исходные шаблоны на 82 и 19 слайдов, 1440×810 pt; их нельзя подставлять в старый движок без адаптации. План миграции — в `references/decisions.md` внутри скилла.

## Права на ресурсы

Лицензия Golos Text находится рядом со шрифтами. Корпоративные шаблоны и логотипы не объявляются свободно лицензированными этим репозиторием; условия их использования определяются правообладателем.
